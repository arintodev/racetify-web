\## Users (users)

\## Social Accounts (social\_accounts)

user social account e.g. google

\## Roles (roles)

user roles, if custom role by org store it with org\_id. org:admin, event:photographer

\## Permissions (permissions)

system permission e.g. org:settings:update, org:events:create, event:gallery:upload

\## Organizations (orgs)

for multi tenant

\## Organization Member (org\_members)

\## Events (events)

event owned by org

\## Event Races (races)

race in events. e.g. Marathon, 7K Fun Trail
## Event Team (event\_team)

user who has some specific permission in an event

\## Event Participants (participants)

event race participant

\## Gallery Items (gallery\_items) (per event)

images/photo or video (on hold)

\## Gallery Item Bib (gallery\_item\_bibs)

store gallery item bib ocr, number and string

\## Gallery Item Face (gallery\_item\_faces) 

store gallery item faces, referenced to vector database (qdrant)

\## Watermarks (watermarks) (per event)

store watermark used by gallery and certificate (on hold)

\## Generator Templates (generator\_templates) (per event) for bib and certificate

store template of bib generator and certificate generator

\## Fonts (fonts)

store custom font to support bib generator and certificate generator

\## Notifications (notifications)

user notification

\## Invitations (invitaions) for event team and org member

\## Certificates (certificate) for participant certificate

\## Face Enrollment (face\_enrollments)

store user enrolled face. user scoped and org scoped with ref\_id

\## Face Embedding (face\_embeddings) 

store face embeddings of enrolled face id referenced to vector database (qdrant)
